# 🧝‍♀️Marevo

**Marevo** – це атмосферний онлайн-магазин букетів, де кожен може знайти особливу квіткову композицію. Легкість, чарівність і магія в кожному замовленні. 💐✨

## Технології

### Frontend:
- **React** – основа для побудови динамічного інтерфейсу.
- **MUI** – для стильного та зручного UI/UX.
- **GitHub Pages** – хостинг для фронтенду.

### Backend:
- **Node.js** – серверна логіка та обробка запитів.
- **MongoDB** – зберігання даних про букети та користувачів.
- **Render** – деплой бекенду.
- **SendGrid** – відправка email-повідомлень.

## Можливості
- **Авторизація** – зареєструйся або увійди до особистого кабінету.
- **Придбання букетів** – обирай, замовляй та даруй емоції.
- **Сповіщення на email** – отримуй інформацію про реєстрацію через SendGrid.
