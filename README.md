
### **MAREVO | A Modern Floral E-commerce Experience**



Ласкаво прошу до [[**MAREVO**](s-chili.github.io/marevo/)] — сучасного, адаптивного, повнофункціонального веб-застосунку для електронної комерції, присвяченого продажу ексклюзивних букетів квітів. Цей проєкт демонструє мої навички у створенні динамічних, орієнтованих на користувача інтерфейсів та є відмінним прикладом роботи з архітектурою SPA (Single-Page Application).

---

### **Ключові технології**

* **React**: Сучасна JavaScript-бібліотека для побудови користувацьких інтерфейсів.
* **React Router**: Для створення плавної навігації між сторінками без перезавантаження.
* **MUI (Material-UI)**: Бібліотека компонентів, що базується на Material Design, для швидкої та елегантної розробки інтерфейсу.
* **Axios / Fetch API**: Для ефективної взаємодії з бекендом та керування запитами.
* **`gh-pages`**: Для автоматизації процесу розгортання проєкту на GitHub Pages.
* **ESLint / Prettier**: Для забезпечення високої якості та єдиного стилю коду.

---

### **Основні функції**

* **Автентифікація користувачів**: Повноцінна система реєстрації, входу та виходу з акаунта. Стан авторизації зберігається в `AuthContext`, що робить його доступним для всіх компонентів.
* **Керування профілем**: Користувачі можуть переглядати та оновлювати свої особисті дані, а також завантажувати фотографію профілю.
* **Кошик та замовлення**: Система дозволяє переглядати доступні букети та формувати замовлення.
* **Обрані товари**: Користувачі можуть додавати товари до списку обраного для подальшого перегляду.
* **Адаптивний дизайн**: Інтерфейс коректно відображається на будь-яких пристроях, від мобільних телефонів до десктопів.
* **Взаємодія з бекендом**: Проєкт взаємодіє з бекенд-сервісом через асинхронні запити, що забезпечує динамічне оновлення даних без перезавантаження сторінки.
